# Calculator

A fully functional on-screen calculator built with HTML, CSS, and vanilla JavaScript. This project is the final assignment from The Odin Project's Foundations course.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal number support
- Chained calculations
- Clear (C) and delete/backspace functionality
- Responsive button layout with visual feedback on hover/click

## Live Demo

Live Solution: https://top-jscalculator.netlify.app

## Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/tsilvalisbon/calculator.git
   cd calculator
   ```
2. Open `index.html` in your browser.
3. Use your mouse to perform calculations.

## Project Requirements

This project fulfills the core requirements from The Odin Project:

- Functions for `add`, `subtract`, `multiply`, and `divide`
- An `operate` function that takes an operator and two numbers
- HTML calculator with buttons for digits, operators, and `=`
- JavaScript logic to update display and handle button clicks
- Support for decimal numbers and chained operations
- Clear button to reset the calculator

## Technologies

- HTML5
- CSS3 (Flexbox/Grid)
- Vanilla JavaScript (DOM manipulation, event handling)
